# AME Framework Diagrams

This directory organizes visual materials associated with the Autonomous Micro-Enterprise (AME) research framework.

Planned materials include:

- AMEA — multi-agent orchestration and runtime architecture
- AMEI — market-interface architecture and its relationship to the operational core
- AMES — security runtime architecture
- Cross-pillar diagrams showing the relationship among AMEA, AMEE, AMEG, AMEF, and AMES

Diagrams will be added with appropriate source attribution and references to the corresponding published research papers.

The AMEI market-interface layer surrounds the five operational pillars; it is not a sixth sibling pillar.
