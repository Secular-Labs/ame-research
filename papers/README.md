# AME Research Papers

This directory organizes the published research papers associated with the Autonomous Micro-Enterprise (AME) framework.

The canonical publication records are maintained on Zenodo and SSRN and are linked from the main repository README.

The six components are AMEA, AMEE, AMEG, AMEF, AMES, and AMEI. AMEI describes the surrounding market-interface layer; it is not a sixth sibling operational pillar.

Paper-specific summaries and supporting materials may be added here as the research collection develops.
